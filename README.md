Project Name:
         Android Knowledge Hub
   
  Android Knowledge Hub is my first Android mini-project, developed using Android Studio. The          application provides simple and organized information about different areas of software development and technology.
The goal of this project is to create a simple learning application where users can explore different technology topics through interactive cards and dedicated information pages.

Technologies Used: 
        Android Studio,Kotlin,XML,Android SDK,Gradle.

 What i learn:
 
Creating Android Activities
Designing layouts using XML
Using LinearLayout and ScrollView
Working with TextView and Button
Creating drawable backgrounds and gradients
Using colors and string resources
Connecting different Activities
